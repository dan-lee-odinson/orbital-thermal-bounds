# orbital-thermal-bounds

Reduced-order, environment-coupled radiator model and machine-verified
thermodynamic bounds for heat rejection in **orbital data centers**.

This site renders the repository's documentation. The package itself
(`orbital_thermal`) is a reduced-order, one-node radiator model — **not** validated
against flown hardware and **not** intended for flight design or certification.

## Start here

- **Reference architectures** — public design points reproduced and compared as
  trade studies, including [Starcloud 2024](reference-architectures/starcloud-2024.md).
- **Repository:** <https://github.com/dan-lee-odinson/orbital-thermal-bounds>
- **Install:** `pip install orbital-thermal`
