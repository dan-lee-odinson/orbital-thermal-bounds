# Getting Help

- **Documentation:** start with the
  [Wiki](https://github.com/dan-lee-odinson/orbital-thermal-bounds/wiki) —
  [Installation](https://github.com/dan-lee-odinson/orbital-thermal-bounds/wiki/Installation),
  [Running the Simulation](https://github.com/dan-lee-odinson/orbital-thermal-bounds/wiki/Running-the-Simulation),
  [API Reference](https://github.com/dan-lee-odinson/orbital-thermal-bounds/wiki/API-Reference),
  and [Troubleshooting](https://github.com/dan-lee-odinson/orbital-thermal-bounds/wiki/Troubleshooting).
- **Reproduction or installation trouble:** open a *Reproduction problem* issue with the
  requested details (OS, Python version, package version/commit, exact command, full
  traceback).
- **A scientific or mathematical concern:** open a *Scientific / mathematical discrepancy*
  issue — these are explicitly welcomed.
- **A feature idea:** open a *Feature request* issue describing the research use.
- **Security / supply-chain:** see [SECURITY.md](SECURITY.md).

This is a single-maintainer, independent research project; responses are best-effort.
