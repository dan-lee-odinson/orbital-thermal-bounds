# Security Policy

## Scope

`orbital_thermal` is **scientific research software**, not operational or flight
spacecraft software. "Security" here concerns the repository, its dependencies, the
published package, and the supply chain — not spacecraft operations.

## Reporting a vulnerability

For repository, dependency, package, or supply-chain security concerns (for example a
vulnerable dependency, a compromised build artifact, or leaked credentials), please use
GitHub's **private vulnerability reporting** (Security → Report a vulnerability) on this
repository, or email **dan.lee.odinson@gmail.com** with "SECURITY" in the subject.
Please do not open a public issue for a sensitive security report.

## What is *not* a security issue

- **Scientific or mathematical discrepancies** — open a *Scientific / mathematical
  discrepancy* issue instead (template provided). These are welcomed and reviewed.
- **Reproduction problems** — open a *Reproduction problem* issue.

## Supported versions

Security-relevant fixes target the latest release (currently `v1.0.1`) and `main`.
